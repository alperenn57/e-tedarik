# 📦 E-Tedarik Sistemi

Bu proje, **Web Tabanlı Programlama** dersi için geliştirilmiş bir E-Tedarik (satın alma, ilan ve teklif yönetimi) web uygulamasıdır. 

Şirketlerin ilan açabilmesini, tedarikçilerin ise bu ilanlara teklif verebilmesini sağlar.

---

## ✨ Özellikler
* **Giriş ve Kayıt Sistemi:** Admin, Tedarikçi ve Alıcı rolleri mevcuttur.
* **İlan Yönetimi:** Alıcı firmalar ihtiyaçları için ilan oluşturabilir.
* **Teklif Sistemi:** Tedarikçiler açık olan ilanlara fiyat teklifi verebilir.
* **Sipariş Takibi:** Kabul edilen tekliflerin durumları güncellenebilir.

---

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** *PHP*
* **Veritabanı:** *MySQL*
